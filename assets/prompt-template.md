# 生视频提示词模板（反讽升格专用）

七段式，骨架遵守 `domn-film-seedance-format`。每段 10–25 秒，一条一段，完整可复制。
`[方括号]` 为待填内容。写法细则与样片范例见 `references/06-visual-language.md`。

---

```text
【1.全局设定】
真实电影摄影机实拍的画面，[黄金时刻 / 正午 / 阴天]自然光，[手持肩扛 / 固定机位]，[浅景深]。
主体是真人不是特效：[人物年龄性别身份]，身穿[高贵部分的实体服装与材质]，[交界点描述：如"小腿赤裸"]，[廉价物的实体材质与外观，含上面的字或纹样]。
[动物/道具]是真实的，[无鞍无缰 / 无任何附加装备]，[自然散乱状态]。
全片唯一光源是[方向与高度]的[落日 / 顶光 / 侧逆光]，色温约 [X]K，斜射到[具体照到哪块骨头或哪个面]；[背光面如何补亮]，不出现第二盏灯。

【2.素材绑定】
@图片1 只定义[人物]的长相与体型：[特征]。不得继承：白底、棚拍光、正面证件站姿、图上标注、分格拼贴。
@图片2 只定义[服装与廉价物]的形制与颜色，[廉价物上的字/纹样]以此图为准。不得继承：白底平铺、分格拼贴、包装盒、第二视角。
@图片3 只定义[场景/动物]的[地理与植披 / 形制与毛色]，它是场景参考不是首帧，全片不复制该图的构图。

【3.画面契约】
[人物]特征串：[一次性写全，含交界点与廉价物]；全片不换装。
识别位：[多主体时的区分手段，如"他是画面里唯一的直立人形，小腿始终裸露"]。
同框上限：画内人不超过 1 个、[动物]不超过 1 只。
材质连续：[衣摆 / 鬃毛 / 草尖]不受主体动作起止约束，主体停下后仍各自延迟晃动半拍。

【4.执行契约】
速度契约：段内 [N] 镜、[N-1] 切点，单镜最长 [X] 秒，最短 [Y] 秒。
[闪卡契约：镜N 是 0.08 秒[色系]渐变纯色卡，无主体无文字，只做节奏断点；它前后两镜的机位与光位必须一致。]
[极端特写契约：[某部位]特写全段只出现一次，机位固定不推近，只靠[主体动作]改变角度。]
[收尾契约：最后一镜必须是[廉价物]特写，[上面的字/纹样]占画面中心，全段只出现这一次。]
摄影：机位档位循环——[档1／档2／档3／档4]，相邻两镜不得同档。
运镜：运镜只由走位驱动，[主体]走则机跟，[主体]停则机停；不为情绪推近。
[轴线契约：[A]在画面[左/右]，全段不换边。]
句法主动权：[主体]一律作主语写主动句。
音频：<[画面里真实能听见的声音1]> <[声音2]> <[声音3]>。不要 bgm，不要字幕。

【5.场景】
[地点]，[时间]。唯一光源是[方向与高度]的[光源]，[硬/软]光。空场状态：[无第二个人、无建筑、无标牌等]。

【6.分段计划】
段是叙事单位不是镜头单位，段内多切。
段[X] [名称] [起]–[止]，段内 [N] 镜：
镜1 [起]–[止] [取景]。[主体做什麼，因果链，不写情绪]。
镜2 [起]–[止] [取景]。[同上]。
末：[该段最后一镜给下一段的可承接终态]。

【7.负向约束】
1. 不要卡通渲染、游戏引擎质感或塑料玩具感。
2. 不要出现第二个人／第二只[动物]。
3. 不要破坏造型断层：[不要加袜子 / 不要把短裤改成西裤 / 不要给马加鞍]。
4. 不要叠加字幕条、标题卡、水印或品牌 logo。
5. 不要 bgm、不要解说、不要字幕。
```

---

## 填写时的三条硬要求

1. **廉价物必须声明为实体并写清材质**。写"实体深酒红色橡胶人字拖"，不写"人字拖"。
2. **光只写物理事实**：方向＋色温＋照到哪块骨头。不写"温暖的氛围光"。
3. **运镜只由走位驱动**。人物停了机就停，不为情绪推近，不给情绪大特写——那是狗血，张力交给表演。
