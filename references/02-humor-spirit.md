# 幽默精神七条 · 与六种死法

结构和零件可以抄，抄了不一定好笑。决定成败的是这七条。范本全做到了。

---

## 七条

**一、冷面。** 全片不发一个"我在搞笑"的信号。语气始终是"教你怎么做"，越荒唐越平静。笑点来自落差，不来自表情。旁白一挤眉弄眼，这片就废了。

**二、精准即好笑。** 它没有夸张奢侈品广告，它是**还原**奢侈品广告。海浪、马眼、风吹衣角、无缘由回头，每一个都是真实存在的广告语汇。戏仿的命门是像，不像就只是闹。

**三、不刻薄。** 全程没指名骂谁，没嘲讽具体的人，没地域黑。攻击的是"那套话术"，不是"某个人"。这让它安全，也让它厚道。**笑点落在系统上，不落在人身上。**

**四、共谋。** 观众知道它在反讽，它也知道观众知道，但谁都不说破。只在关键处轻轻捅一下（"这就对了"），然后继续装正经。

**五、平民立场。** 站在穿拖鞋的人这边。拖鞋舒服，拖鞋是"不服"。不仰视奢侈品，也不踩它，平视之后笑一声。这个姿态一变，味道全变。

**六、克制。** 没有一句"你看我这段多好笑"。金句出来就走，不回头，不解释。

**七、认知密度。** 它好笑是因为它真的懂。**幽默的上限是认知的上限。** 不懂的人写出来只会是瞎闹。

## 六种死法

### 死法一：跳出来讲段子

✗ "你以为这就完了？不，还有更离谱的！接下来这块马蹄铁，价值一套房！"
✓ "如果预算允许，最好再加一匹不知道哪里来的白马。"

差别在语气。前者在表演，后者在陈述。**一旦旁白开始期待观众的反应，冷面就破了。**

### 死法二：夸张代替还原

✗ "摆出各种扭曲到不像人类的姿势！"
✓ "一定要鼻孔看镜头。"

"扭曲到不像人类"是形容词，观众脑子里没画面。"鼻孔看镜头"是动作，一秒就有画面。**具体的荒唐比抽象的夸张好笑十倍。**

### 死法三：编造套路

✗ "还要在旁边放一只象征着品牌精神的火烈鸟。"（编的）
✓ "再穿插几帧海浪、马眼、天空、风吹过衣角。"（真实存在的广告语汇）

编的套路观众认不出，不构成"你也见过这个"的共鸣。**笑点依赖观众的既有经验，不是你的想象力。**

### 死法四：笑点落在人身上

✗ "穿着拖鞋的大爷，还以为自己走的是戛纳红毯。"
✓ "要走出一种一路他失去了很多，也得到了很多的感觉。"

前者嘲的是人，后者嘲的是那套表演要求。**一旦嘲人，平民立场就塌了，整片从解构变成霸凌。**

### 死法五：结尾点题

✗ "所以啊，时尚从来不在价格标签上，而在你自己的选择里。"
✓ "托马势。"

范本从不抒情。收口是谐音，不是道理。**一点题，前面的冷面全白费。**

### 死法六：解释笑点

✗ "是不是很荒诞？但这恰恰说明了一个道理……"
✓ "每个镜头看起来都有深意，连在一起又谁也说不清意义。这就对了。"

元评论的正确写法是**只呈现不评论**——把矛盾摆出来，说"这就对了"，然后走。不要替观众总结。

## 一句话判断标准

写完之后问自己：**如果把这段话当成真的教程发给一个外行，他会照着做吗？**

会，就是对的。他甚至可能觉得学到了东西——这才是反讽升格的最高境界。
