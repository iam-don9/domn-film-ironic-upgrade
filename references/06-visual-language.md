# 视觉语言与生视频提示词规格

从样片《如何把人字拖拍成买不起的样子》（1920×1080 / 25fps / 122.8s / 32 镜）抽出。

提示词格式遵守 `domn-film-seedance-format` 的七段式；这份只写**本类型特有**的东西。

---

## 一、三条视觉语法

### 1. 造型断层，笑点在脚踝那一截

样片的主体穿**酒红色短西装套装**（长袖外套＋同料及膝短裤）＋白衬衫＋领带，然后——**赤裸的小腿，和一双深酒红人字拖**。

整套正装走到脚踝以下就断了。这个断层是全片唯一的视觉笑点，**比任何一句文案都直接**，而且不需要观众懂任何话术。

**换题材时的写法**：找到"高贵部分"与"廉价物"在身体或物体上的**交界点**，把交界处拍清楚。蛇皮袋→手与袋口的提绳处；保温杯→西装袖口与杯身；小电驴→皮鞋与踏板。**不要拍整身，拍交界。**

### 2. 廉价物与高贵物同色同材质

样片里西装、人字拖、字幕卡全是酒红／橙红系。**让廉价物和高贵物共享一个颜色**，是"升格"最快的一招——观众的眼睛会先把它们归为一类，脑子才反应过来不对。

**换题材时**：给廉价物一个与话语体系同色系的版本。米其林→给泡面一个米色陶碗；科技发布会→给蛇皮袋一个哑光黑的配色；售楼处→给塑料凳一个香槟金。

### 3. 极短闪卡做节奏断点

样片中段与后段各有一组 **3–4 帧（0.08–0.12 秒）的橙红渐变纯色卡**，无主体无文字。观众只感觉到"闪了一下"。

这正好是文案说的"再穿插几帧海浪马眼天空风吹过衣角，每个镜头看起来都有深意，连在一起又谁也说不清意义"——**闪卡是这句文案的物理形态。**

**硬要求**：闪卡前后两镜的机位与光位必须一致，否则会剪出跳帧感。

---

## 二、节奏结构（2 分钟标配）

| 区间 | 内容 | 单镜时长 |
|---|---|---|
| 0–27s | 慢到近乎静止。大远景、航拍空镜、全身站立 | 4–9.5 秒 |
| 27–50s | 上道具与品牌（白马、骑乘、品牌卡） | 4–6.4 秒 |
| 50–62s | 切廉价物特写（笑点落点） | 0.12–6.3 秒 |
| 62–88s | 姿态与无意义空镜，中间插闪卡 | 0.08–9.6 秒 |
| 88–123s | 回到大远景收尾，最后一镜落在廉价物特写上 | 6–20.8 秒 |

**极端特写全片只出现一次**，放在 68 秒左右，是全片笑点最高点。样片是"鼻孔看镜头"。放第二次就不值钱了。

## 三、七段式里本类型的固定写法

### 【1.全局设定】
第一句锁死实拍：`真实电影摄影机实拍的画面，黄金时刻自然光，手持肩扛，浅景深。`

接着写实体道具声明，**廉价物必须声明为实体并写清材质**：`脚穿实体深酒红色橡胶人字拖，鞋面压印金色「拖」字`。

光源只写物理事实：`唯一光源是画面右侧低空的落日，色温约 2800K，斜射到他的右颊、右肩与右小腿外侧；背光面靠草地反光补亮，不出现第二盏灯。`

### 【2.素材绑定】三张图，一张只干一件事

- `@图片1` 人物长相与体型
- `@图片2` 服装与廉价物的形制与颜色（**廉价物上的字以此图为准**）
- `@图片3` 场景（**声明它是场景参考不是首帧**）

每张都要写"不得继承"。人物图挡白底／棚拍光／证件站姿；服装图挡白底平铺／分格拼贴／包装盒；场景图挡构图复制。

### 【3.画面契约】
特征串写全（含廉价物）。识别位：`他是画面里唯一的直立人形`。同框上限：人不超 1、动物不超 1。材质连续：主体停下后，衣摆／鬃毛／草尖仍各自动半拍。

### 【4.执行契约】本类型必须写的六条

| 契约 | 写法 |
|---|---|
| 速度契约 | `段内 N 镜、N-1 切点，单镜最长 X 秒，最短 Y 秒` |
| 闪卡契约 | `镜N 是 0.08 秒橙红渐变纯色卡，无主体无文字；它前后两镜的机位与光位必须一致` |
| 极端特写契约 | `鼻孔特写全段只出现一次，机位固定不推近，只靠他抬头改变角度` |
| 摄影 | 档位循环逐镜列出，相邻两镜不得同档 |
| 运镜 | `运镜只由走位驱动，人走机跟，人停机停；不为情绪推近` |
| 句法主动权 | `男主一律作主语写主动句` |

音频只写画面里真实能听见的：`<马蹄踏过湿草的闷响> <草叶摩擦声> <风声>`。不要 bgm。

### 【5.场景】
地点＋唯一光源＋空场状态。空场状态要写死：`无第二个人、无建筑、无道路标牌`。

### 【6.分段计划】
`段是叙事单位不是镜头单位，段内多切。` 每镜写时间范围＋取景＋动作因果链。每镜末句给"末："收尾状态。

### 【7.负向约束】五条，本类型固定这五条

1. 不要卡通渲染、游戏引擎质感或塑料玩具感
2. 不要出现第二个人／第二只动物
3. 不要破坏造型断层（不要加袜子、不要把短裤改成西裤、不要给马加鞍）
4. 不要叠加字幕条、标题卡、水印或品牌 logo
5. 不要 bgm、不要解说、不要字幕

第 3 条按题材改内容，但**职责永远是"保护造型断层"**。

---

## 四、后期叠加，不写进提示词

全部中文口播字幕、品牌字幕卡、闪卡、收尾谐音字幕——**一律在剪辑阶段叠加**。

按 `domn-film-seedance-format` 的规则，文字不交给视频模型，否则必出糊字与错字。这一点在【7.负向约束】第 4 条里也要拦一次。
