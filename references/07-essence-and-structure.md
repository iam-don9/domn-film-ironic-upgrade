# 本质与结构 · 以及表层不可继承清单

这份回答两个问题：这个案例**到底是什么**，以及**哪些东西不能跟着一起搬走**。

写新片前必读。**先读这份，再看样片。**

---

## 一、本质：它卖的不是笑点，是命名

观众早就隐约觉得奢侈品广告很空，但说不出来。这片把那套套路逐条列出来，给它一个荒谬的名字（托马仕），于是那个模糊的感觉一下有了抓手。

**笑，是认知被命名的瞬间。**

由此推出三条，它们是后面所有规则的根：

1. **不是编笑话，是指认。** 观众笑的前提是**他早就认得这个东西**。你不生产笑点，你只是把它摆到光下。
2. **因此套路必须是真的。** 编造的套路无人指认，笑点直接归零。不熟就先查，查不到就换壳。
3. **因此语气必须冷。** 一旦你自己先笑了，观众就从"指认"变成"被逗"，笑点贬值一个量级。

## 二、三层：哪些能继承，哪些不能

| 层 | 内容 | 处置 |
|---|---|---|
| **表层** | 草原、蜿蜒河、白马、酒红短西装、人字拖、黄金时刻、鼻孔特写、橙红闪卡 | **不继承**。这是这一个案例的皮肤，跟着搬就是临摹 |
| **中层** | 奢侈品广告的九条标准动作 | **可换**。换话语体系就整套换掉 |
| **深层** | 五层结构骨架 + 幽默精神七条 | **必须继承**。这就是类型本身 |

**绝大多数"换了题材还是像抄的"问题，都出在表层没换干净。**

## 三、结构：五层骨架

叙事五层，视觉五层，一一对应。

### 叙事

| 层 | 职责 |
|---|---|
| 1 命题层 | A（最廉价）× B（最昂贵），一句话焊死 |
| 2 教程层 | 把 B 的九条标准动作逐条还原。这是"复述" |
| 3 升级层 | 三步递进荒谬。把一个歪标准推三步 |
| 4 破功层 | 元评论，说破 B 的空 |
| 5 焊死层 | 谐音，把 A 和 B 焊成一个词 |

### 视觉

| 层 | 职责 |
|---|---|
| 1 交界点 | 高贵部分与廉价物在身体或物体上的**物理交界**。拍交界，不拍整身 |
| 2 同色 | 让廉价物与高贵物共享一个色系，观众的眼睛先归为一类，脑子才反应过来不对 |
| 3 闪卡 | 0.08–0.12 秒纯色卡，无意义的节奏断点 |
| 4 极端特写一次 | 全片只一次，放在 55%–65%，是笑点最高点 |
| 5 收尾回到廉价物 | 全场最后一个画面是它 |

### 节奏

慢（0–22%）→ 上道具（22–40%）→ 切廉价物特写（40–50%）→ 姿态与空镜（50–72%）→ 收尾远景（72–100%）

## 四、原创性只存在两处（★）

这个结构里，**只有两处需要真正动脑，其余全是结构的必然**：

**一、交界点在哪。** 高贵部分与廉价物在身体或物体上的物理交界在哪里。

样片是**脚踝**——短西装短裤、赤裸小腿、人字拖，正装走到脚踝以下就断了。这一笔是样片**最原创的地方**，比草原和白马原创得多。

**二、递进三步填什么。** 第一句要听起来完全成立，第二句开始歪，第三步离谱。

> 判据：**如果你的交界点和递进三步跟样片一样，那就算换了物和壳，也仍然是复制。**

交界点的设计方法：分别列出"高贵物的持用/穿着方式"和"廉价物的真实用法"，找它们**唯一重叠的那个接触面**。手袋是挂在臂弯，蛇皮袋是攥着提绳扛——重叠面是"手与提绳"。

## 五、表层不可继承清单

以下每一项都**只属于样片这一个案例**。新片里出现任何一项，即判为临摹：

- 草原 / 高原草甸 / 蜿蜒河 / 远山积云
- 黄金时刻 / 落日侧逆光 / 长约 2800K 的暖光
- 酒红 / 勃根地色系
- 短西装套装（长袖外套＋同料及膝短裤）
- 白马，以及任何"与叙事无关的动物"
- 人字拖 / 拖鞋 / 任何鞋
- 鼻孔看镜头，以及任何**身体部位**的极端特写
- 橙红渐变闪卡
- 骑乘

**替代原则**（每一条怎么换）：

| 不可继承 | 换成什么 |
|---|---|
| 与叙事无关的高贵动物 | 与廉价物有**材质或功能关系**的东西 |
| 身体部位极端特写 | **廉价物本身的微结构** |
| 样片的橙红闪卡 | **廉价物自己的颜色** |
| 黄金时刻 | 该廉价物**真实使用时的光**（正午顶光 / 白炽灯 / 阴天散射） |
| 草原 | 该廉价物**真实出现的场所** |

## 六、原创性自检（写完必过）

1. 交界点：我设计的交界处，跟样片的"脚踝"是同一个地方吗？**是 → 重写**
2. 道具：我用的道具，是"与叙事无关的高贵动物"吗？**是 → 换成与廉价物有材质或功能关系的东西**
3. 极端特写：拍的是身体部位吗？**是 → 换成廉价物本身的微结构**
4. 闪卡：颜色来自样片吗？**是 → 换成廉价物自己的颜色**
5. 递进三步：能一眼看出是跟着样片的句法填词吗？**能 → 重想**
