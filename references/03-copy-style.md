# 文案写作风格规格

这份是本技能的核心。**写口播文案前必读。**

风格不是形容词堆出来的，是可量化的。下面每一条都带数字或可判定的标准，照着卡。

---

## 零、怎么用这份文件：留口癖，拆模具

这份文件是**工具箱**，不是**模具**。照着它写，不等于把样片的 45 行拿来做名词替换。两条铁律，一条必须留，一条必须破。

### 0.1 招牌口癖必须保留（灵魂所在）

下面五件是这套东西的**灵魂调料**，换了题材也必须原样在。它们的价值在于观众一听就知道"是这一挂的"——**去掉它们，剩下的只是普通的反讽文案**。

| 口癖 | 句法装置 | 落点 | 模板 |
|---|---|---|---|
| **定调口癖** | 浑身上下就两个字：**[冷感大词]**。 | 人物与动作段开场，一句话定气质 | T3 |
| **自我揭短口癖** | 如果预算允许，最好再加**[一个高规格道具]**，**[顺手承认其荒谬／多余]**。 | 道具升格段 | T5 |
| **平行荒谬递进** | 毕竟一旦 **[A]**、**[B]**，或者干脆 **[C]**，这样的 **[物件]** 就自带 **[神圣属性]**。 | 品牌／名号段，三步平行 | T4 |
| **冷面元评论收束** | ……**这就对了**。 | 全片最高处，一声冷淡点穴 | T9 |
| **终极升华底牌** | 此时此刻，就可以上升到 **[领域]** 的终极奥义：**[一句万能大词]**。 | 升华段 | T10 |

保留的是**句法装置**，不是句子内容：**容器照用，里面装新题材自己的东西。**

五件里，平行荒谬递进与元评论收束同时也在必选零件清单里（`05-part-library.md`）；谐音收口是结构件（焊死层），不属口癖。

### 0.2 坚决杜绝"外科手术式逐句完形填空"

**病症**：把参考文案拿来 1:1 逐句映射——把"走两步停五米"改成"走三步停五秒"；给"白马"硬找一个动物替身；整篇 45 行严丝合缝做名词替换。这种产物一眼就能被认出是抄文案，因为**骨架、顺序、句长、槽点位置全部照搬，只换了名词**。

**规避三法则**：

1. **结构解绑** —— 叙事结构完全由**新题材的真实装腔逻辑**驱动，不迁就原片的段落节奏。写餐饮就按"产地溯源 → 龟毛挑剔 → 极少量摆盘 → 敬畏自然"的真实套路推进。样片的段落顺序只是**一种**排法，不是唯一排法。
2. **原生行话与动作** —— 动作、道具、槽点必须来自**新题材自身真实存在的生活细节**，不是从样片里做对应翻译。样片用"鼻孔看镜头"，你的题材不一定也要找一个"奇怪的身体指令"；它真实的行话是什么，就写什么。
3. **散装调用** —— 把招牌口癖当成**工具箱里的散件**，按新题材自己的节奏挑最恰当的 **3–4 处**关键节点自然落点；不按样片顺序整排，不要求每件各占一段。节点宁少勿多；两件口癖在题材里天然同处时可并到同一处（这条只放开口癖，零件本身仍不堆叠，见 `05-part-library.md`）。递进三段与元评论收束必须分处两地。

**判据**：把新文案和样片逐行并排——除了名词不同，**行数、顺序、每行长短、槽点位置**是否几乎一致？是 → 重写。

## 一、先建立语感

动笔前，先读一遍 `04-source-annotated.md`。那是唯一的范本，读两遍再写。

判断语感到位没有，只有一个办法：**把写好的文案读出声**。读起来像在教人做事、脸上没表情，就对了。读起来像在讲段子，就重写。

---

## 二、节奏规格（可量化）

源片：《9月26日》，121 秒，45 行字幕，约 393 字。

| 指标 | 规格 |
|---|---|
| 语速 | **190–220 字/分钟**（约 3.2 字/秒）。比平常口播慢一半，留白才是笑点的一部分 |
| 每行字数 | **6–14 字**，典型 8–10 字 |
| 行均时长 | **2.5–2.8 秒/行** |
| 全片行数 | 2 分钟对应 **40–50 行** |
| 长句处理 | 一句话拆成 2–3 行，行间留 0.3–1.0 秒停顿，不要一口气说完 |
| 收口段 | **越接近结尾，行越短**。源片最后 6 行是 2/4/4/3/4/4/3 字，故意切碎，形成顿挫 |

最容易犯的错：**写太密**。190 字/分钟听起来几乎是在发呆，但正是这个密度让每句都有重量。写完之后数字数，超了就砍，不要舍不得。

## 三、语气规格

**冷面。** 全片不发一个"我在搞笑"的信号。

具体表现：

- 用陈述句和祈使句，不用反问句煽动、不用感叹句
- 全程"教你怎么做"的姿态，不跳出来评论
- 越荒唐的内容，语气越平静。落差就是笑点，不要把落差说出来
- 副词极少。不写"非常""特别""极其"

**自我揭短**是冷面的高级用法：在给出荒谬指令后，顺手承认它没道理，但语气不变。源片写"一匹不知道哪里来的白马"——连广告人自己都懒得给道具找理由，这句比白马本身更好笑。

## 四、句法模板库

这些是从范本里抽出来的**散件**，按新题材自己的结构各取所需。**不要一次全用，也不要按样片顺序整排。**

### 教程推进词（串起全片的骨架）

> 首先…… 然后…… 如果预算允许…… 紧接着…… 等他…… 铺垫到这里…… 记住…… 此时此刻就可以上升到……

### T1 反差开场

> 如何把 **[廉价物]** 拍成 **[高语境]** 的样子。

要求：一句话里两个词之间必须隔着明显的价值差距。14 字以内。

### T2 反常识场地

> 首先拍一个你这辈子都不会 **[带着廉价物]** 去的地方。

### T3 空话描述空话

> 浑身上下就两个字：**[形容词]**。
> 要走出一种"一路他失去了很多，也得到了很多"的感觉。

这是范本里最妙的一招：**用一句空话，去描述另一种空话**。任何"说不清到底什么意思但听起来很高级"的要求，都可以这么写。

### T4 递进三段（必用）

> 毕竟一旦 **[条件 A]**、**[条件 B]**，或者干脆 **[条件 C]**，这样的 **[对象]** 就自带 **[高级属性]**。

先立一个歪标准，再顺着它推三步，一步比一步离谱，但句法完全平行。三步是下限也是上限——两步不够味，四步开始啰嗦。

### T5 道具升格 + 自我揭短

> 如果预算允许，最好再加 **[一个莫名其妙的高贵道具]**，**[一句承认它没道理的话]**。

### T6 态度文案滑稽化

> 紧接着来句表达态度的文案：
> "**[廉价物的动作]** 不是 **[负面词]**，**[它的好处]** 也是 **[正面词]**。

句式是奢侈品 slogan 的标配（不是 A，是 B），内容却把最不体面的东西包装成一种反抗。6 字一行，两句对仗。

### T7 反转定义

> 记住：**[正常的做法]** 是 **[低级品类]**，越不 **[正常]** 就越 **[高级品类]**。

源句："姿势正常是生活照，姿势越不正常就越时尚。"用断言的方式给出一个荒唐的行业标准。

### T8 指令式荒诞

> 一定要 **[具体到能执行的荒唐动作]**。

源句："一定要鼻孔看镜头。"指令越具体越好笑，不要写"摆个奇怪的姿势"。

### T9 元评论（必用）

> 这种高端大片里，所有的 **[物件]** 都不是 **[物件]**，是为了表达出 **[X]** 和 **[Y]**。
> 每个镜头看起来都有深意，连在一起又谁也说不清意义。
> **这就对了。**

在笑点最高处停下来，把行业的空点破，然后用赞赏的语气收住。"这就对了"四个字是开关——它不说破"我在反讽"，只是承认。

### T10 万能底牌

> 此时此刻就可以上升到 **[领域]** 的终极奥义：**[一句所有高端叙事最后都会掏出来的废话]**。

源句用"做自己"。每个话语体系都有这么一张牌（传承 / 长期主义 / 诗和远方 / 自律），找到它，翻过来给人看。

### T11 谐音收口（必用）

> 比如——**人自为 [X]，人生自 [X]。**
> 又或者——**心如 [XY]，自成其 [Z]。**
> **[XYZ]。**

五到七行，每行 2–4 字，切碎。最后一行是焊死的那个词：**它必须同时含住"廉价物的字"和"话语体系的核心字"**。源片"托马势"＝拖鞋的"托"＋爱马仕的"马/仕"＋玄学词"势"，一个词焊三样东西。

## 六、词汇表

**可用**（教程推进与冷面评价）：首先、然后、紧接着、等他、铺垫到这里、记住、如果预算允许、最好、一定不能、一定要、此时此刻就可以上升到、比如、又或者、自带、毫无缘由、谁也说不清、这就对了、正常人不会。

**禁用**（一出现就破功）：

- 感叹与网感词：哈哈哈、笑死、绝了、离谱、绷不住、家人们
- 点题与抒情：其实、说白了、不得不说、值得一提的是、由此可见、这告诉我们、生活就是这样
- 煽情收尾：每一个 XXX 都值得被尊重、致敬每一个 XXX
- AI 腔：此外、不仅……而且、值得注意的是、在这个充满 XX 的时代
- 三段式排比：它是 A，是 B，更是 C

**标点**：几乎不用感叹号；不用省略号抒情；不用括号补刀；破折号只在"比如——""又或者——"这种引导处用，全片不超过 3 处。

## 七、禁忌清单

| 禁忌 | 为什么 |
|---|---|
| 解释笑点 | 写"是不是很荒诞"就等于告诉观众"这里该笑了"，笑点立刻死 |
| 夸张模仿 | 戏仿的命门是像。写"夸张到离谱的姿势"不如写"鼻孔看镜头" |
| 编造套路 | 观众认不出的套路不构成笑点。不熟就先查 |
| 嘲讽具体品牌或个人 | 笑点必须落在话术上，不落在人身上 |
| 地域黑、人身攻击、阶层优越感 | 一旦带着优越感写，平民立场就塌了，整片变味 |
| 结尾点题升华 | 范本从不抒情。收口是谐音，不是道理 |
| 密度超标 | 超过 220 字/分钟就开始像念稿 |
| 谐音直接用 | 谐音只做到"听得出"，别拿它卖货 |

## 八、写完自查

1. 读出声。像在教人做事、脸上没表情吗？
2. 数字数。在 190–220 字/分钟区间内吗？
3. 看行长度。有没有超过 16 字的行？有就拆。
4. 找三个必用零件：递进三段、元评论、谐音收口，都在吗？
5. 搜一遍禁用词表，一个都不能有。
6. 最后一行。那个谐音，同时含住"物"和"壳"了吗？
7. 立场。全片是站在廉价物这边，还是在笑用它的人？
8. 并排。把新文案和样片逐行并排——除了名词不同，行数、顺序、每行长短、槽点位置是不是几乎一致？是就重写。
9. 口癖。招牌口癖五件（定调／自我揭短／平行荒谬递进／元评论收束／升华底牌）是不是都在，且句法装置没被改写？
