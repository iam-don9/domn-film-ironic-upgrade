# 方法论推导 · 四条变量轴与选型判据

SKILL.md 给的是执行流程，这份讲的是"为什么这么选"，以及一组配方做完之后怎么换着来。

---

## 一、公式

> **[国民级廉价物] × [装 X 话语体系] → 用说明书语气逐条拆解 → 谐音/双关焊死**

前两项是变量，第三项是固定语气，第四项是收口。范本《9月26日》只是这条公式的一个解：拖鞋 × 奢侈品广告。

---

## 二、变量轴 A：换物

判据（满足越多越好）：人人见过用过；自带地域或阶层标签；被主流审美判为土或廉价；名字可谐音；形体简单、一眼入画、好拍。

| 物 | 可谐音的方向 | 反差点 |
|---|---|---|
| 蛇皮袋 | 袋袋相传 / 一袋宗师 / 蛇皮世家 | 编织袋 vs 真蛇皮顶级皮革 |
| 塑料袋 | 爱马袋 | 超市赠品 vs 手袋 |
| 大裤衩 | — | 居家 vs 秀场 |
| 保温杯 | — | 中年养生 vs 冷萃/威士忌 |
| 小电驴 | — | 代步 vs 超跑 |
| 老干妈 | — | 下饭酱 vs 米其林 |
| 二锅头 | — | 大排档 vs 单一麦芽 |
| 塑料凳 | — | 排档 vs 家居设计 |
| 秋裤 | — | 保暖 vs 时装周 |
| 泡面 | — | 宵夜 vs 摆盘 |
| 搪瓷缸 | — | 怀旧 vs 器皿美学 |
| 凉席 | — | 夏夜 vs 软装 |

**选物的隐藏判据：这个词本身能不能横跨两个世界。** 最好的是"蛇皮袋"——"蛇皮"在奢侈品语境里是顶级皮革，在菜市场语境里是几块钱的编织袋。同一个词，两个价格。这种词不用谐音就自带反差。

## 三、变量轴 B：换壳

判据：有稳定可识别的套路；大众熟悉到能秒懂；有标志性词汇或句式可被滑稽化；最好有可谐音的品牌名或术语。

| 话语体系 | 可拆的套路 | 标志性词汇 |
|---|---|---|
| 奢侈品广告 | 空旷场地、从容人物、莫名道具、反常姿态、无意义空镜、"做自己" | 世家、传承、限量 |
| 科技发布会 | 黑场、极简舞台、一句形容词定调、参数诗意化 | 重新定义、one more thing、极致 |
| 米其林餐厅 | 摆盘、侍酒、产地溯源、主厨理念 | 风土、层次、回甘 |
| 售楼处 | 沙盘、样板间、话术逼定 | 稀缺、尊享、价值洼地 |
| 券商路演 | 宏大叙事、赛道图、长期主义 | 护城河、赛道、长期主义 |
| 高端茶酒 | 山头、年份、开汤 | 回甘、陈化、山头 |
| 健身 / 瑜伽 | 身体叙事、自律叙事 | 自律、塑形、能量场 |
| 冥想 / 灵修 | 向内探索、自然意象 | 疗愈、能量、向内 |
| 相亲市场 | 条件清单、匹配度 | 优质、匹配度、门当户对 |
| 职场黑话 | 术语包装日常动作 | 抓手、颗粒度、对齐、闭环 |
| 学术论文 | 术语包装常识 | 范式、场域、本研究 |
| 中医养生 | 玄学因果 | 气血、湿气、调理 |
| 成功学 / 微商 | 认知叙事 | 认知、圈层、破局 |

**换壳的硬门槛：必须真的熟。** 拆出来的每一条都得是真实存在的做法。不熟就先查，查不到就换壳。瞎编的套路观众认不出来，笑点直接归零。

## 四、变量轴 C：换体裁

范本的体裁是"拍摄教程"。同一个内核可以换载体：

看房指南、点菜指南、相亲指南、面试指南、开会指南、简历指南、装修指南、送礼指南、旅游攻略、健身计划、学习计划、育儿指南。

体裁一换，"说明书语气"的载体就变了，但冷面复述的内核不变。

---

## 五、变量轴 D：换方向

- **升格**（范本）：把便宜的拍成贵的。
- **降格**：把贵的拍成便宜的。"如何把爱马仕拍出广东省鞋的感觉"。笑点反向成立，且更狠——因为观众默认你会仰视，你偏不。
- **平移**：把 A 领域的话术整套搬到 B 领域。用售楼处的话术讲相亲，用论文的话术讲泡面。错位本身就是笑点，不需要额外造梗。

---

## 六、为什么"复述"是核心动作

这类片子的笑点不是"编"出来的，是"摆"出来的。

编出来的梗需要观众理解你的笑点；摆出来的套路是观众本来就认得的东西，你只是把它放到不该在的地方。**命中率差一个量级。**

所以流程里把"拆套路"（步骤 2）放在"排零件"（步骤 3）和"写文案"（步骤 4）之前，不是顺序偏好，是因果：**没有原料，就没有笑点。**

想不出梗的时候，回去把步骤 2 的清单再拆细一层，比硬想有用得多。
